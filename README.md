# Galaxy AI — Mintaka & the Fold

An explorable static 3D world built with Three.js: the Milky Way hub,
Mintaka, Earth, Pandora, and Asgard. No build step — serve this folder
with any static host.

Run locally:

```sh
python3 -m http.server 8080
# then open http://localhost:8080
```

Three.js loads from a CDN on first load; everything else is local.
